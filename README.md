# Credit Card Fraud Detection

A machine learning project that explores how classification models can identify fraudulent credit card transactions in a highly imbalanced dataset.

What I Did:

* Explored transaction data and class imbalance
* Applied leakage-safe feature scaling
* Trained and compared:

  * Logistic Regression
  * K-Nearest Neighbors (KNN)
  * Gaussian Naive Bayes
  * Support Vector Machine (SVM)
* Evaluated models using **Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrix**

#Key Takeaway

Since fraud represents only a very small portion of the transactions, accuracy alone can be misleading. This project focuses on understanding the trade-off between detecting fraud effectively and avoiding unnecessary false alerts.
